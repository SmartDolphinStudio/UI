# Pyramid Diagram

> Ordered by cadence and leverage.

![Preview](preview.png)

Overview

The **Pyramid Diagram** is a self-contained editorial diagram. Ordered by cadence and leverage. It ships as a **single-file React component** (inline SVG + Tailwind CSS) with no chart library, no data files, and no external stylesheets — copy the file in and it renders immediately.

Content pyramid showing short posts, essays, long-form guides, and a flagship book ordered by shipping cadence and leverage.
